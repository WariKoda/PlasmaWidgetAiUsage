# Plasma 5.27 Port Design

## Scope

The `plasma-5.27` branch targets Plasma 5.27, Qt 5.15, KDE Frameworks 5, and Python 3.10 or newer. It preserves the normalized provider schema and all Claude multi-profile behavior from the Plasma 6 implementation. Supporting older Plasma 5 releases or Python versions is outside this branch.

## Compatibility layer

The Python provider and collector helpers remain unchanged. QML imports receive explicit Qt 5 and KF5-compatible versions. `main.qml` uses an `Item` root and the Plasma 5 `Plasmoid.*` attached properties; executable data sources use `PlasmaCore.DataSource`. The configuration page uses an `Item` root because `org.kde.kcmutils` is a Plasma 6 requirement.

The package keeps its stable plugin ID but removes the Plasma 6 minimum-version marker, adds the Plasma 5 declarative-applet metadata, and uses `kpackagetool5` in the installer. The README clearly identifies this branch as Plasma 5.27-only and records the Python 3.10 floor.

## Validation boundary

Static tests enforce the Plasma 5 imports, root types, data source, metadata, installer, and absence of known Plasma 6-only symbols. Existing provider tests continue to validate shared helper behavior. Python compilation, XML/JSON parsing, shell syntax, and whitespace checks run locally. Final runtime acceptance requires a real Plasma 5.27 session with `qmlscene`/`plasmoidviewer` or installation in a panel; that test is intentionally deferred to the user.
